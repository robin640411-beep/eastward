# 一路向東

手機直向像素公路 RPG，使用瀏覽器本機存檔。遊戲過程不呼叫 AI 或外部 API。

## 遊玩

選擇種族與職業開始，按「發動引擎」擲 D10 前進。每段路消耗汽油與駕駛體力，夜間更累；乘客在行車時恢復體力。每次停靠必有事件，追加事件機率依序為 75%、50%、25%。

建築可進入使用服務，再探索其他區域。選擇執行者以使用其職業、種族特性。修車廠提供維修及改裝；新車座位不足時，先在同行者介面遣散同伴。

戰鬥中，每名清醒角色各選一個指令，敵我按速度結算。睡眠遭襲時，無守夜者會讓敵方先攻；只有被擊中的角色會醒來。

進度到達 100 即抵達末日綠洲。燃料不足且未能找到燃料或替代車輛時，神諭決定旅程結局。沒有保證可獲勝的路線。

存檔保存在目前瀏覽器；背包可匯出 JSON 留存。清除瀏覽器網站資料會移除本機存檔。關閉頁面不會讓世界時間繼續前進。

## 開發與檢查

需要 Node.js 與 Python 3，沒有 npm 套件依賴。

```sh
node --test tests/*.test.mjs
python3 tools/check_art.py
python3 -m http.server 8765 --directory dist
```

`spec/` 保存設計與神諭原始資料；`python3 tools/sync_data.py` 同步到遊戲。`python3 tools/make_art.py` 重建原創像素 SVG。圖像與遊戲 source 皆包含在本專案。

本機瀏覽器測試可執行 `node tools/make-qa.mjs` 產生 `dist/qa.html`。該頁會覆寫本機測試存檔，只供 QA；發布前必須刪除 `dist/qa.html`。
