# 一路向東

手機直向像素公路 RPG，使用瀏覽器本機存檔。遊戲過程不呼叫 AI 或外部 API。

## 遊玩

選擇種族與職業開始，按「發動引擎」擲 D10 前進。每段路消耗汽油與駕駛體力，夜間更累；乘客在行車時恢復體力。每次停靠必有事件，追加事件機率依序為 75%、50%、25%。

建築可進入使用服務，再探索其他區域。選擇執行者以使用其職業、種族特性。修車廠提供維修及改裝；新車座位不足時，先在同行者介面遣散同伴。

戰鬥中，每名清醒角色各選一個指令，敵我按速度結算。睡眠遭襲時，無守夜者會讓敵方先攻；只有被擊中的角色會醒來。

進度到達 100 即抵達末日綠洲。燃料不足且未能找到燃料或替代車輛時，神諭決定旅程結局。沒有保證可獲勝的路線。

存檔保存在目前瀏覽器；背包可匯出 JSON 留存。清除瀏覽器網站資料會移除本機存檔。關閉頁面不會讓世界時間繼續前進。

## 開發與檢查

需要 Node.js 與 Python 3，沒有 npm 套件依賴。

```sh
node --test tests/*.test.mjs
python3 tools/check_art.py
python3 -m http.server 8765 --directory dist
```

`spec/` 保存設計與神諭原始資料；`python3 tools/sync_data.py` 同步到遊戲。`python3 tools/make_art.py` 重建原創像素 SVG。圖像與遊戲 source 皆包含在本專案。

本機瀏覽器測試可執行 `node tools/make-qa.mjs` 產生 `dist/qa.html`。該頁會覆寫本機測試存檔，只供 QA；發布前必須刪除 `dist/qa.html`。

## 首版範圍

外星入侵故事篇；12 種族、20 職業、32 優點、20 缺點、100 姓名、100 外號、100 公路與 100 建築事件、36 種族超能力。圖像共 344 個 SVG：240 人物、12 頭像、8 車型與20加座變體、16敵人、28場景、16圖示、4改裝圖示。

數值為可調整的首版設定，沒有食物、負重、裝備耐久或即時探索移動。人物與敵人使用簡單像素圖，行車與戰鬥以輕量 Canvas 動畫呈現。

## 公路動畫與事件場景更新

主畫面改為 384×240 的即時像素舞台，以約 30 FPS 顯示多層遠景、電線桿、路面、車輪與揚塵。每次行車預設 12 秒，可略過動畫；時間與資源仍由原本的回合規則結算。

新增 202 個事件圖像（總共 546 個 SVG），包含加油站、修車廠、斷橋、巢穴、塌陷地板等物件；火焰、雨、霧、孢子與電火花依事件顯示。場景按鈕可直接進入或處理事件，戰鬥可點敵人鎖定，顯示攻擊與數值變化。

執行 `python3 tools/make_event_art.py` 重建事件圖像與映射；圖鑑可瀏覽全部事件圖像。新增圖像只在遇到時載入，頁面隱藏時暫停繪圖。

## 連續鏡頭、地貌與戰鬥介面

行車前在狀態副本上預覽同一個擲骰結果，只載入即將遇到的場景，不改變正式隨機數或提前扣除資源。車輛行進中漸漸拉遠鏡頭，前方物件進入視野，減速後停靠；停靠前後使用同一個鏡頭與車身尺寸。`journey-view-model.js` 集中保存鏡頭、光線、地貌與敵人位置。

12 種地貌為鹽原、峽谷、森林、市郊、海岸、工業帶、濕地、沙丘、農田、雪原、異星侵蝕區與東方綠帶。各有建築、植被或地形；經過地貌邊界時漸變。每段一小時隨行車動畫呈現連續光線，夜間有星月、車燈及亮起的城市窗戶。

人物戰鬥參考 MOTHER3 的中央敵人、下方隊伍狀態配置，使用本作原創圖像和背景。每人先選指令，再點選畫面中的敵人或下方治療對象；全隊指令完成前可按「上一人」修改。超能力有獨立選單。既有速度、睡眠與回合規則維持原樣。官方參考：https://www.nintendo.co.jp/data/software/manual/manual_pc9j_00.pdf

本輪在 Chrome 390×844、360×780 檢查畫面；實際操作攻擊、藥品、超能力、返回上一人、行車自動停靠與進入建築。`qa/camera/` 保存本機檢查畫面與可複製至 dist 的鏡頭檢查頁，發布內容不含測試頁或測試存檔。尚未在實體手機驗證效能。
